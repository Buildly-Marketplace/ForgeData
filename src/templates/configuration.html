Onboarding Status

Cloud Provider Credentials

Add Cloud Credential

Use the API to add credentials. Example:

curl -X POST http://localhost:8000/api/onboarding/credentials/gcp \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My GCP Account",
    "project_id": "my-project-123",
    "use_gcloud_cli": true,
    "description": "Production GCP account"
  }'

Or use the Quick Setup API: POST /api/onboarding/quick-setup

Database Connections

Add Database Connection

Use the API to add connections. Example:

curl -X POST http://localhost:8000/api/onboarding/database-connections \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Production Database",
    "database_type": "postgresql",
    "host": "db.example.com",
    "port": 5432,
    "database": "mydb",
    "username": "user",
    "password": "pass",
    "use_ssl": true
  }'
